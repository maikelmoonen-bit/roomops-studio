# Capability matrix

Every GUI capability mapped to the Microsoft service, the commands RoomOps runs, the permissions needed, read/write behavior, how it is validated, and its limitations. "Live status" is **pending** for every Microsoft 365 operation until verified against an authorized tenant (see [VERIFICATION](VERIFICATION.md)).

Role abbreviations: **EXA** Exchange Administrator (or a role group with Recipient Management for recipients and Organization Configuration for calendar processing), **PLA** Places Administrator or a custom role with TenantPlacesManagement, **GRA** delegated Microsoft Graph permission.
